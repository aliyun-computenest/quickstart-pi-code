## Pi Coding Agent 简介

Pi 是一个开源的、运行在终端中的 AI 编程智能体（Agentic Coding Tool）。它以「最小化代理框架」为设计理念，提供强大的基础能力，同时高度可定制——你可以按自己的工作流自由扩展，而不必迁就工具本身。Pi 能理解代码库上下文，通过自然语言帮助你完成代码编写、调试、重构与测试，并可在你的授权下执行 Shell 命令。除交互式终端外，Pi 还支持脚本化 JSON 输出、RPC 与可嵌入 SDK 等多种使用方式。本服务在阿里云 ECS 上一键部署 Pi 运行环境，并自动对接阿里云百炼（DashScope）大模型，开箱即用。

### 核心特性

- **全代码库理解** — 自动索引和理解整个项目结构，无需手动指定上下文
- **多文件编辑** — 一次对话中可同时创建、修改多个文件，完成跨模块重构
- **终端命令执行** — 在用户授权下运行 Shell 命令、安装依赖、执行测试，反馈结果并自动修复
- **多种使用方式** — 支持交互式终端、print/JSON 脚本化输出、RPC 与嵌入式 SDK，适配不同工作流
- **高度可定制** — 不内置固定的子代理或规划模式，通过配置与扩展 API 贴合你的流程
- **模型自由接入** — 兼容 15+ 模型服务商（OpenAI 兼容 / Anthropic 兼容等），本服务默认对接阿里云百炼（DashScope）
- **多语言支持** — 覆盖 Python、JavaScript/TypeScript、Go、Rust、Java 等主流编程语言

## 部署流程

1. 单击部署链接，进入服务实例部署界面，根据界面提示填写参数（包括实例规格、实例密码以及百炼 API-KEY），可以看到对应询价明细，确认参数后点击**下一步：确认订单**。

2. 确认订单完成后同意服务协议并点击**立即创建**。

3. 等待部署完成后远程连接服务器。

4. 连接后执行以下命令启动 Pi：
    ```shell
    sudo su root
    cd /root
    pi
    ```
